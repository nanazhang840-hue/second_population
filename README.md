# SECOND POPULATION ·看见另一种人口

物品能耗人口普查 — 城市道路监控识别模拟

把街道监控画面里的每一辆车、每一个路灯、那一台空调外机，都当作「人口」来清点：它们在制造阶段消耗了多少能源和水，在运营阶段排放了多少碳。共 40 个识别目标。

---

## 快速开始

网站是纯静态的，但**必须通过 HTTP 服务访问**（`file://` 协议下 `tracks.json` 和视频会被浏览器拦截）。

任选一种方式：

### 方式一：Python（推荐，已自带脚本）

```bash
python nocache_server.py
```

然后打开 <http://127.0.0.1:8020/index.html>

> `nocache_server.py` 发送 `Cache-Control: no-store`，改代码后刷新必定拉最新版本，不会被浏览器缓存坑到。

### 方式二：Node.js

```bash
npx serve -l 8020.
```

### 方式三：VS Code

安装 Live Server 扩展，右键 `index.html` → Open with Live Server。

> **直接双击 index.html 打不开**，因为 `fetch('tracks.json')` 和 `<video>` 在 `file://` 下会被 CORS 拦截。

## 首次进入：GLITCH 启动界面

打开后先播放约 3 秒的故障艺术启动序列（终端式日志逐行揭示），点**ENTER SYSTEM**或按 `Enter` 进入主站，也可以点 `SKIP INTRO` 直接跳过。

进入后视频画面默认带轻度「信号劣化」效果，右下角`SIGNAL DEGRADATION` 可切 **OFF / LOW / HIGH**。

### 点开任意目标

点击画面里的识别框，或左侧「标注清单」里的任意一行：

1. **阶段一几何扫描** — 该物体专属造型的三维模型旋转采集，进度条 + 准星网格
2. **阶段二档案** — 模型视觉列 + 身份表 / 碳记录 / 资源连接，逐块揭示

`Esc` 关闭。`←` / `→` 切换上/下一个目标。

空调目标 `SP-0004` 走的是另一套模块（`ac-archive/`，来自 handoff v7），点击后进入独立的空调档案体验。

## 配色约束（改代码前请注意）

全站**只用黑色 `#000000` + `#A8D3E0`**（含其透明度层级），包括 glitch 效果——通道分离是靠亮青/暗青两级模拟的，没有引入其他色相。新增样式请沿用 `:root` 里的 `--ink-*` 变量，不要写死新的颜色。

```css
--ink    #A8D3E0   --ink-90 / 70 / 50 / 30 / 15 / 08（透明度层级）
--bg     #000000
```

## 无障碍

所有动画都响应 `prefers-reduced-motion: reduce`——关闭抖动、扫描光带、噪声位移和入场转场，保留静态的通道重影。

## 已知限制

- `tracks.json` 里的能耗、碳排数据是**示意估算值**，非实测
- 部分目标的碳记录尚未核验，界面中标注为 `UNVERIFIED` / `PENDING`
- 监控视频是固定机位，识别框位置写死在 `tracks.json` 的归一化坐标里
