第二人口 · 本地预览（5.4.9 档案空间原型）
==========================================

【最省事的打开方式】
1. 把整个 zip 解压到任意目录，路径建议全英文，例如 D:\second-population。
2. 看主流程：双击根目录的「启动预览.bat」
   看档案空间三维原型：双击根目录的「启动档案空间.bat」
3. 会弹出一个黑色命令行窗口 + 自动打开默认浏览器。
   黑窗口就是服务器本体，不要关；关掉即停止预览。
4. 浏览器地址如果是 127.0.0.1，说明是本机；地址栏里会显示实际端口号。

【怎么算成功】
- 主流程（index.html）：出现黑色开场页，中间是「第二人口」大标题与监控相机，底部有滚动提示。
- 档案空间（space.html）：出现一个深色工业大厅，里面有车、路灯/监控杆、门架标识、护栏围挡、井盖；
  按 V 切换到斜俯视监控视角，按 L 切换标签，点击物体可聚焦。
- 如果直接看到浏览器报「无法访问此网站 / ERR_CONNECTION_REFUSED」，说明服务没起来或黑窗口被关了。

【端口冲突怎么办】
- 脚本会自动从 8120 往后找空闲端口（到 8160），不需要手动改。
- 黑窗口里会打印两行地址，例如：
    主流程：http://127.0.0.1:8121/index.html
    档案空间：http://127.0.0.1:8121/space.html
  以黑窗口打印的端口为准，手工改地址栏也能进。
- 如果 8120–8160 全被占用，脚本会红字提示启动失败；关掉占端口的程序后再双击一次。

【重要：不要直接双击 html 文件】
不要双击 index.html / space.html。
那样浏览器会用 file:// 打开，ES 模块脚本与 data/*.json 的读取会被浏览器安全策略拦截，
结果就是白屏或只剩无样式文字——这不是包坏了，是打开方式不对。
必须先起本地服务（双击上面两个 bat 之一），再从 127.0.0.1 打开。

【依赖】
- 只需要 Windows 自带的 PowerShell 5.1，不需要安装 Node / Python / 任何第三方包。
- 主流程的 mp4 视频、档案图片、三维模型全部在包内，离线可用，不联网。
- Mac 需要另写启动脚本（本次未包含）。
